Book Shop Management System (C++ OOP Project)

Overview
This is a simple Book Shop Management System built in C++ using Object-Oriented Programming concepts. The project simulates a basic library system where users can view books, borrow them, return them, and provide ratings.

The system is designed using a class-based structure and demonstrates real-world interaction logic using loops and conditions.

Features
- Display book information
- Borrow books with availability check
- Track number of times a book is borrowed
- Return book functionality
- User rating system (0 to 5 scale)
- Menu-driven system with continue/exit option
- Multiple book objects handled in a single program

Concepts Used
- Classes and Objects
- Encapsulation (private data members)
- Constructor
- Conditionals (if-else logic)
- Loops (while loop for menu system)
- Boolean state handling (availability tracking)
- Basic input validation
- Simple user interaction system

How It Works
1. The program starts with a menu system.
2. User selects whether to view books or exit.
3. User selects a book from the available list.
4. Book details are displayed.
5. User can:
   - Borrow the book
   - Return the book
   - Rate the book
6. System updates availability and borrow count accordingly.
7. User can continue or exit the program.

How to Run
1. Compile the program:
   g++ filename.cpp -o output

2. Run the program:
   ./output

Notes
- Each book has its own availability status.
- Borrowing is only possible if the book is available.
- Rating must be between 0 and 5.
- Simple menu system is used for repeated interaction.
